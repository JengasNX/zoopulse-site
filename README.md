# Зоопульс

Публичная демо-версия: https://jengasnx.github.io/zoopulse-site/
Публикация через GitHub Actions после push в main.
GitHub Pages обслуживает только статический интерфейс: аккаунты, база,
платежи и доставка заявок здесь не запускаются. Серверные HTTP-заголовки
из Next.js не применяются Pages; noindex в HTML сохраняется.

Независимая платформа заботы о животных. Next.js 16 / TypeScript / React /
Tailwind / Three.js. Сейчас — демонстрационный интерфейс, не production-сервис.

## Локальный запуск
Требуется Node.js 20.9+ (тесты TS напрямую используют возможности Node 22.18+).

```powershell
npm ci
npm run dev
```

Адрес: http://localhost:3000. Production-проверка: `npm run build`,
затем `npm start`. Переменная `TEST_BASE_URL` меняет адрес smoke-тестов.

## Проверки
```powershell
npm run build
npm test
node scripts/audit-smoke.mjs
npm audit --omit=dev
```

Smoke-тесты требуют запущенный сервер. Они проверяют HTTP/H1/заголовки/404,
а не все клики, доступность, юридическую готовность или Core Web Vitals.
`npm test` проверяет сравнение, правила доступа и SQL-миграции в PGlite.
Он не требует Docker, SMTP или сетевой БД. Инструкция локального PostgreSQL:
`db/README.md`. Миграции настоящей БД — только отдельной командой
`npm run db:migrate` с явно заданными переменными и подтверждением.

## Документы
- `SPECIFICATION.md` — итоговое рабочее ТЗ.
- `IMPLEMENTATION-PLAN.md` — очередь реализации MVP.
- `DESIGN.md` — утверждённый стиль и фактический статус визуальных проверок.
- `AUDIT.md` — аудит, исправления и незакрытые вопросы.
- `BUSINESS-MODEL.md` — подтверждённые бизнес-решения.
- `db/README.md` — подготовленная, ещё не применённая схема PostgreSQL.

## Границы демо
Каталог/статьи вымышлены; формы не отправляют данные. Нет серверных
аккаунтов, кабинетов, модерации, доставки заявок, платежей и рабочей карты.
Избранное/сравнение/тема хранятся в браузере. Демо закрыто от индексации.
Пожертвования в будущей версии направляются напрямую приютам.
Не используйте демонстрационные контакты и не вводите настоящие личные данные.

Не публиковать проект как готовый бизнес-сервис до выполнения P1–P4.
